# Shared Project Templates

This directory contains standardized scaffolding templates for developers and AI agents adding new components to CampusGuide.

---

## Available Templates

- [`backend-module/`](file:///D:/CampusGuide/templates/backend-module/): Standardized 4-domain backend module package template (Controller, Service, Repository, DTOs, Unit & Security IT Tests).
- [`frontend-component/`](file:///D:/CampusGuide/templates/frontend-component/): Boilerplate React component structure with CSS module and service bindings.
- [`api-specification-template.md`](file:///D:/CampusGuide/templates/api-specification-template.md): Standard template for documenting REST APIs in `docs/api/`.
