# Campus Domain Overview

The Campus Domain (`com.campusguide.campus`) manages physical and organizational entities within the institution. It contains three core modules:

1. **Councils Module** (`com.campusguide.campus.council`) - Governance bodies, student councils, and administrative bodies. See [councils.md](councils.md).
2. **Notices Module** (`com.campusguide.campus.notice`) - Official campus notices, announcements, and bulletins. See [notices.md](notices.md).
3. **Events Module** (`com.campusguide.campus.event`) - Aggregate root for workshops, hackathons, seminars, and campus events. See [events.md](events.md).
