# Mobile Councils & Communities Feature Specification

This document details the mobile user interfaces for browsing student councils, community forums, interactive posts, and council applications.

---

## 1. Feature Overview
Mobile users can explore campus student organizations, read community discussion feeds, comment on posts, RSVP to events, and submit applications for council positions.

---

## 2. Key Screen Workflows

- **Council Directory**: Browse active council profiles, leadership executive lists, and open positions.
- **Community Discussion Feed**: Infinite scroll list of community posts with embedded image attachments, upvotes, and nested comment drawers.
- **Application Submission Form**: Interactive form for applying to council roles or student club memberships.
