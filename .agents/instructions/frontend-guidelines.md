# Frontend Coding & UI Guidelines

## Technology Stack
- React 18+
- Vite
- Vanilla CSS / Modern CSS design tokens

## Design & Formatting Guidelines
1. **Formatting (.editorconfig)**: Enforce 2-space indentation for JavaScript, JSX, JSON, CSS, SCSS, and HTML files. Always preserve LF line endings and final newlines.
2. **Visual Excellence**: Avoid basic/generic default styling. Use rich modern design tokens, cohesive color palettes, dark modes, smooth hover states, and dynamic visual layouts.
3. **Component Modularity**: Keep UI components isolated, small, and reusable inside `frontend/src/components/`.
4. **API Integration**: Centralize API service calls in `frontend/src/services/` or `frontend/src/api/`. Handle loading, success, and error states gracefully.
5. **No Placeholders**: Ensure mock data or icons are realistic and complete.
