# Refactoring Prompt Template

```markdown
## Task
Refactor [Component / Module] to improve architecture, maintainability, or performance.

## Constraints
1. Do NOT break existing API contracts or response structure.
2. Preserve all existing docstrings, comments, and external configurations.
3. Ensure domain isolation boundaries are respected.
4. Run verification tests after every refactoring step to ensure zero regressions.
```
